# DefiUnion

Utilizes blockchain-enabled architecture for real-time, multi-node consensus-driven processing of financial transactions within a decentralized protocol network.

With DefiUnion, you get a lightweight tool that stays out of your way.

**What you get**

- Utilizes blockchain-enabled architecture for real-time,
- multi-node consensus-driven processing of financial

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/DefiUnion.git`
2. `cd DefiUnion`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure DefiUnion, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
